# HTML 기초 개념 정리

## 1. HTML 기본 구조

HTML 문서는 기본적으로 `DOCTYPE → html → head → body` 구조로 작성한다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>웹 문서 연습</title>
</head>
<body>

    <h1>웹 개발 기초</h1>
    <p>HTML</p>
    <p>CSS</p>

</body>
</html>
```

### 주요 태그

| 태그                       | 설명                    |
| ------------------------ | --------------------- |
| `<!DOCTYPE html>`        | HTML5 문서임을 선언         |
| `<html>`                 | HTML 문서의 전체 영역        |
| `<head>`                 | 문서의 설정 및 정보를 작성       |
| `<meta charset="UTF-8">` | 한글 등 다양한 문자를 정상적으로 표시 |
| `<meta name="viewport">` | 모바일 화면에 맞게 화면 크기 설정   |
| `<title>`                | 브라우저 탭에 표시되는 제목       |
| `<body>`                 | 실제 웹 브라우저에 표시되는 내용    |

# 2. 제목 태그

HTML에서는 `<h1>`부터 `<h6>`까지 제목의 크기와 중요도를 표현할 수 있다.

```html
<h1>웹 개발 기초</h1>
<h2>레드향 샐러드 레시피</h2>
<h3>상품 구성</h3>
<h4>상품 구성2</h4>
<h5>상품 구성3</h5>
<h6>상품 구성4</h6>
```

### 특징

* `<h1>`이 가장 중요한 제목
* `<h6>`으로 갈수록 하위 제목
* 페이지의 구조를 나타내는 용도로 사용
* 단순히 글자 크기를 변경하기 위한 용도로 사용하지 않는 것이 좋음

# 3. 문단과 줄바꿈

## `<p>` 문단

문단을 작성할 때 사용한다.

```html
<p>HTML은 웹 페이지의 구조를 만드는 언어입니다.</p>
<p>CSS는 웹 페이지의 디자인을 담당합니다.</p>
```

`<p>` 태그가 끝나면 다음 문단으로 넘어간다.

---

## `<br>` 줄바꿈

문단 내부에서 줄을 바꿀 때 사용한다.

```html
<p>
    첫 번째 줄입니다.<br>
    두 번째 줄입니다.
</p>
```

### 차이

```text
<p> → 문단을 구분
<br> → 줄을 바꿈
```

---

# 4. 주석

HTML에서 주석은:

```html
<!-- 주석 -->
```

으로 작성한다.

주석은 브라우저 화면에 표시되지 않는다.

```html
<!-- 자바스크립트 내용 -->
<!-- <p>자바스크립트</p> -->
```

### VS Code 단축키

```text
Ctrl + /
```

주석을 빠르게 추가하거나 제거할 수 있다.

# 5. 글자 강조

HTML에는 글자의 의미를 강조하기 위한 여러 태그가 있다.

## `<b>` 굵게 표시

```html
<b>레드향</b>
```

단순하게 글자를 굵게 표시한다.

---

## `<strong>` 중요성을 강조

```html
<strong>혈액 순환, 감기예방</strong>
```

중요한 내용을 강조한다.

일반적으로 단순히 굵게 표시하는 `<b>`보다 **의미를 가진 강조**에 적합하다.

---

## `<i>` 이탤릭체

```html
<i>좋은 것으로 알려져 있다.</i>
```

글자를 기울여 표시한다.

---

## `<em>` 의미 있는 강조

```html
<em>한라봉과 귤을 교배</em>
```

강조하고 싶은 내용을 표현한다.

### 정리

| 태그         | 용도        |
| ---------- | --------- |
| `<b>`      | 단순 굵게     |
| `<strong>` | 중요한 내용 강조 |
| `<i>`      | 기울임       |
| `<em>`     | 의미 있는 강조  |

---

# 6. 인용문

## `<blockquote>`

다른 내용이나 문장을 인용할 때 사용한다.

```html
<blockquote>
    비타민 C와 비타민 P가 풍부해 혈액 순환 등에 좋은 것으로 알려져 있다.
</blockquote>
```

브라우저에서 일반 문장보다 들여쓰기된 형태로 표시된다.

---

# 7. 수평선

## `<hr>`

콘텐츠를 구분하는 수평선을 표시한다.

```html
<hr>
```

예:

```html
<p>레드향 설명</p>

<hr>

<h2>레드향 샐러드 레시피</h2>
```

# 8. 목록

HTML에서는 크게 **순서가 있는 목록**, **순서가 없는 목록**, **설명 목록**이 있다.

---

## 8-1. 순서가 있는 목록 `<ol>`

순서가 중요한 목록을 작성할 때 사용한다.

```html
<ol>
    <li>재료를 준비합니다.</li>
    <li>레드향을 자릅니다.</li>
    <li>모든 재료를 섞습니다.</li>
</ol>
```

결과:

```text
1. 재료를 준비합니다.
2. 레드향을 자릅니다.
3. 모든 재료를 섞습니다.
```

### `type` 속성

```html
<ol type="I">
```

로마 숫자:

```text
Ⅰ
Ⅱ
Ⅲ
```

```html
<ol type="a">
```

알파벳:

```text
a
b
c
```

---

# 9. 순서가 없는 목록 `<ul>`

순서가 중요하지 않은 목록에 사용한다.

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

결과:

```text
• HTML
• CSS
• JavaScript
```

### `<li>`

`<ol>`이나 `<ul>` 내부에서 각각의 항목을 표현한다.

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

# 10. 설명 목록

## `<dl>`, `<dt>`, `<dd>`

용어와 설명을 나타내는 목록이다.

```html
<dl>
    <dt>선물용1</dt>
    <dd>소과 13~16과</dd>
    <dd>중과 10~12과</dd>

    <dt>선물용2</dt>
    <dd>소과 15~18과</dd>
    <dd>중과 10~12과</dd>
</dl>
```

### 각각의 역할

| 태그     | 의미        |
| ------ | --------- |
| `<dl>` | 설명 목록 전체  |
| `<dt>` | 설명할 용어    |
| `<dd>` | 용어에 대한 설명 |

구조:

```text
<dl>
 ├─ <dt>용어</dt>
 └─ <dd>설명</dd>
</dl>
```

# 11. 이미지

## `<img>`

이미지를 삽입할 때 사용한다.

```html
<img src="images/spring.png" alt="제주도" width="450">
```

### 주요 속성

| 속성      | 설명                     |
| ------- | ---------------------- |
| `src`   | 이미지 파일의 경로             |
| `alt`   | 이미지가 표시되지 않을 때 나타나는 설명 |
| `width` | 이미지 너비                 |

### 경로 예시

```html
<img src="images/mic.jpg" alt="공지사항">
```

현재 HTML 파일을 기준으로:

```text
HTML
├── 01
│   └── 1.html
└── images
    └── mic.jpg
```

이라면:

```html
<img src="../images/mic.jpg">
```

처럼 상대경로를 사용해야 한다.

---

# 12. `<figure>`와 `<figcaption>`

이미지와 이미지 설명을 하나의 묶음으로 표현할 때 사용한다.

```html
<figure>
    <img src="results/images/spring.png" alt="제주도" width="450">
    <figcaption>가장 먼저 봄을 맞이하는 제주도</figcaption>
</figure>
```

### 역할

```text
<figure>
    이미지
    설명
</figure>
```

* `<figure>` → 이미지나 콘텐츠를 하나의 그룹으로 묶음
* `<figcaption>` → 해당 콘텐츠의 설명

---

# 13. 여러 이미지 표시

여러 개의 이미지를 하나의 `<figure>` 안에 넣을 수도 있다.

```html
<figure>
    <img src="results/images/spring.png" alt="제주의 봄">
    <img src="results/images/summer.png" alt="제주의 여름">
    <img src="results/images/fall.png" alt="제주의 가을">
    <img src="results/images/winter.png" alt="제주의 겨울">

    <figcaption>사계절의 제주도</figcaption>
</figure>
```

# 14. HTML 속성

HTML 태그에는 추가적인 정보를 제공하는 **속성(attribute)**을 사용할 수 있다.

기본 형태:

```html
<태그 속성="값">
```

예:

```html
<img src="images/mic.jpg" alt="공지사항">
```

여기서:

```text
src = 속성
images/mic.jpg = 속성값

alt = 속성
공지사항 = 속성값
```

# 15. 실습 예제 - 방송국 모집 페이지

```html
<h1>수습국원 모집</h1>

<h2>방송에 관심있는 새내기 여러분 환영합니다</h2>

<p>
    교내 방송국에서 신입생을 대상으로 수습국원을 모집합니다.
    학부나 전공에 상관없습니다.
</p>

<ul>
    <li><b>모집 기간</b> : 3월 2일 ~ 3월 11일</li>
    <li><b>모집 분야</b> : 아나운서, PD, 엔지니어</li>
    <li><b>지원 방법</b> : 양식 작성 후 이메일 접수</li>
</ul>

<h3>혜택</h3>

<ol type="a">
    <li>수습기자 활동 중 소정의 활동비 지급</li>
    <li>정기자로 진급하면 장학금 지급</li>
</ol>

<img src="images/mic.jpg" alt="공지사항">
```

### 사용된 태그

```text
<h1> ~ <h3> → 제목
<p>              → 문단
<br>             → 줄바꿈
<ul>             → 순서 없는 목록
<ol>             → 순서 있는 목록
<li>             → 목록 항목
<b>              → 굵게 표시
<img>            → 이미지
```

# 17. 핵심 정리

```text
HTML
│
├── 문서 구조
│   ├── html
│   ├── head
│   └── body
│
├── 텍스트
│   ├── h1 ~ h6
│   ├── p
│   ├── br
│   ├── b / strong
│   └── i / em
│
├── 목록
│   ├── ol
│   ├── ul
│   └── dl
│
├── 이미지
│   ├── img
│   ├── figure
│   └── figcaption
│
└── 기타
    ├── blockquote
    ├── hr
    └── 주석
```

> **HTML = 웹 페이지의 구조를 담당**
>
> **CSS = 웹 페이지의 디자인을 담당**
>
> **JavaScript = 웹 페이지의 동작을 담당**
